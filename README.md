# Dungeon Maze Escape

## Game Description
Dungeon Maze Escape is a 2D maze game where the player controls a yellow Pac-Man-style character. The goal is to collect four keys while avoiding moving guards and navigating through the maze.

## How to Play
- **Left Arrow:** Move left
- **Right Arrow:** Move right
- **Up Arrow:** Move up
- **Down Arrow:** Move down
- **R Key:** Restart the game

## Game Rules
1. Collect all four yellow keys.
2. Avoid the four moving enemy guards.
3. If a guard touches you, you lose one life and return to the starting position.
4. If you get hit three times, you lose the game.
5. Collect all four keys to unlock the exit.
6. Reach the green exit door to win.

## Game Features
- Four collectible keys
- Four moving enemy guards
- Maze walls with collision detection
- Vector2 player and enemy movement
- Win and lose conditions
- Restart feature

## How to Run
1. Download or clone the GitHub repository.
2. Open the project in Visual Studio.
3. Run the game using the Start button.
4. Use the arrow keys to play.
